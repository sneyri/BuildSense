# BuildSense: управление мышью и горячие клавиши — отчёт

Дата: 2026-10-29. Режимы: «Машиностроение» и «Архитектура».

## 1. Что реализовано

### Машиностроение
| Функция | Как работает |
|---|---|
| **Соединить детали** (кнопка «Соединить детали» / клавиша J) | Щёлкаете поверхность первой детали, затем второй. Программа по реальной геометрии определяет, что вы выбрали (торец, уступ, цилиндр, отверстие), предлагает способ, показывает предпросмотр и расстояние до/после, после «Применить» создаёт **настоящее сопряжение** в существующей модели сборок |
| Подсветка и привязки | Наведение подсвечивает поверхность (кольцо для плоскости, оболочка и пунктирная ось для цилиндра); первая деталь синяя, вторая оранжевая; жёлтый маркер привязки («центр торца», «ось цилиндра»); подсказка у курсора |
| Простые названия | «Совместить оси», «Прижать поверхности», «Оставить зазор», «Выровнять вровень», «Закрепить на месте». Технические названия (Соосность, Грани встык, Осевое смещение…) — во всплывающей подсказке варианта |
| Объяснение невозможного | Смесь цилиндра и плоскости, одна и та же деталь, болтовое отверстие, фаска, обе детали закреплены, детали из разных сборок, конфликт с существующими сопряжениями — понятный текст вместо тихого отказа |
| Манипуляторы | **G** — цветные стрелки X/Y/Z (перемещение строго по оси), **R** — дуги вращения вокруг осей (вокруг центра габарита). Подсказка у курсора с координатами/углом **во время** перетаскивания; шаг 1 мм / 5° при включённых привязках, без округления — при выключенных |
| Перетаскивание самой детали | Как раньше: по полу, с Shift (можно нажать посреди перетаскивания) — по высоте |
| Правила сборки при перемещении | Свободная — двигается. Закреплённая — двигается вместе со всей сборкой (с пояснением). **Соединённая — не двигается**: появляется панель с кнопками «Отключить соединения этой детали», «Убрать из сборки», «Двигать закреплённую деталь» |
| Состояние видно | Кромки: закреплённая — синие, положение задано сопряжениями — зелёные; в строке под сценой: «свободна / закреплена / положение задано сопряжениями» |
| Закрепить (K), Дублировать (Ctrl+D), виды NumPad 7/1/0, привязки (X) | Реализованы, все через историю и решатель |
| Подсказка новичку | Показывается один раз; «Больше не показывать»; включается обратно в окне «?» |

### Архитектура
| Функция | Как работает |
|---|---|
| **Ручки концов стены** (план) | У выбранной стены (не из контура) на плане — квадратные ручки на обоих концах. Тянете: меняются настоящие `position`, `rotation`, `size.length`; во время перетаскивания видна длина; проёмы остаются на тех же местах в мире; Shift — по осям, Esc — отмена |
| Горячие клавиши | Единые, см. таблицу ниже |
| Подсказки | При выборе инструмента «Стена» и при выборе первой свободной стены |

Остальное из списка (создание стен кликами с длиной, замыкание контура, привязки, дублирование, копирование, этажи, план/3D, undo/redo, предупреждения) **уже существовало** и не переписывалось.

## 2. Горячие клавиши (реально реализованные)

Единый менеджер [js/ui/hotkeys.js](js/ui/hotkeys.js): один слушатель, коды клавиш (работает в русской раскладке), не срабатывает при вводе текста (INPUT/TEXTAREA/SELECT/contenteditable), пропускает события, уже обработанные локально (холст плана), при открытом диалоге работают только Esc и «?». Окно справки (`?`, `F1`, кнопка «Горячие клавиши» на вкладке «Вид») строится из **реально зарегистрированных** действий и позволяет переназначать клавиши (клик по клавише → нажать новую; конфликты отклоняются; сохраняется в браузере).

| Клавиша | Машиностроение | Архитектура |
|---|---|---|
| Ctrl+Z / Ctrl+Y, Ctrl+Shift+Z | отменить / повторить | то же |
| Ctrl+S | сохранить `*.mech.json` | сохранить JSON |
| Ctrl+D | дублировать деталь | дублировать выбранное |
| Delete | удалить деталь | удалить выбранное |
| Esc | отмена перетаскивания → сброс выбора в «Соединить» → выход из режима → снять выделение | отмена операции → инструмент «Выбор» → изометрия/изоляция → снять выделение |
| Enter | применить соединение | — |
| V | выбрать | выбор |
| G | стрелки перемещения | перемещение (выбор + подсказка) |
| R | дуги вращения | повернуть размещаемый объект на 90° |
| J | соединить детали | — |
| K | закрепить / снять закрепление | — |
| X | привязки вкл/выкл | привязки вкл/выкл |
| F | показать всё | показать всё |
| NumPad 7 / 1 / 0 (альтернатива: 7 / 1 / 0) | вид сверху / спереди / изометрия | то же |
| W, I | — | инструмент «Стена», изоляция |
| ? , F1 | справка | справка |

**Не реализовано сознательно:** `S` (масштабирование), потому что в проекте нет общего инструмента изменения размеров, а у вида масштаб — колесо мыши.

## 3. Геометрические типы для соединения

| Выбрано | Предлагается |
|---|---|
| цилиндр ↔ цилиндр / отверстие (наружная поверхность, центральное отверстие, цилиндр ступени вала) | «Совместить оси» (+ «Развернуть деталь») |
| торец/уступ ↔ торец/уступ | «Прижать поверхности», «Оставить зазор» (с вводом мм), «Выровнять вровень» |
| закрепление | «Закрепить на месте» (K) |

**Нет:** сопряжений по болтовым отверстиям фланца (в модели сопряжений такого типа нет; клик по ним объясняет это), по фаскам, по произвольным граням, угловых и касательных сопряжений, выбора вершин для соединения. Привязка к «вершине» поддержана только как центры граней и оси; прилипание к ближайшим вершинам не реализовано.

## 6. Что проверено в браузере (приложение запущено, часть кликов — настоящей мышью/клавиатурой через панель браузера)

- Режим «Соединить детали»: клавиша J (настоящее нажатие), щелчок по цилиндру вала и по втулке (настоящая мышь) → панель с вариантом «Совместить оси», расстояние 60 мм → 0 мм, «Поедет «Втулка 1»», предупреждение о пересечении, кнопка «Применить» (настоящий щелчок) → в проекте появились сборка A1, закреплённый вал, сопряжение `coaxial`, статус «partial», запись в истории.
- Второй шаг через имитацию выбора (`_pick`, без мыши): плоскости → «Прижать поверхности / Оставить зазор / Выровнять вровень»; применение → статусы `fixed` / `solved`, оба сопряжения `ok`.
- Стрелка X перемещения (настоящее перетаскивание): `x = 10`, камера не повернулась, запись в истории. Дуга Z (клавиша R, перетаскивание): `rotation.z = −35` (шаг 5°).
- Соединённая деталь: перетаскивание стрелки → панель блокировки с тремя действиями, положение не изменилось.
- Клавиши (синтетические события клавиатуры на документе): Ctrl+D, Ctrl+Z, Ctrl+Y, Delete, `?`, Esc в машиностроении и архитектуре; X, W, G, Esc в архитектуре; при фокусе в поле ввода Delete / Ctrl+D / J не срабатывают.
- Ручка стены на плане (настоящее перетаскивание): длина 4 → 7,5 м, статус «Стена: длина 7,5 м», запись в истории.

## 7. Оставшиеся ограничения и нереализованное

- Нет ручек высоты и толщины стены, ручек для других элементов (фундамент, лестница, перекрытие) — только концы свободных стен. Стены из контура меняются вершинами контура (как раньше).
- Нет вращения деталей мышью вокруг произвольной оси или по плоскости; вращение — вокруг осей X/Y/Z в мировых координатах.
- Предпросмотр соединения показывает итоговое положение полупрозрачной деталью; анимации перехода нет.
- Привязка к вершинам и к «ближайшим контактным положениям» не реализована (только центры граней и оси, шаг 1 мм / 5°).
- Не реализованы: сопряжение по болтовым отверстиям, масштабирование (S), быстрые команды создания всех объектов архитектуры.
- Не проверено в браузере: Ctrl+S (скачивание файла) реальным нажатием, Ctrl+Shift+Z, NumPad-виды реальной клавиатурой, переназначение клавиши в окне справки (проверено только в Node), оформление всех тем, поведение на тач-экране.
- Панель «Соединить детали» занимает заметную часть вида на маленьком окне; сворачивать её нельзя (закрывается кнопкой «Отмена»).
- Часть кликов в браузере проверялась через синтетические события (`_pick`, клавиатура), это указано выше; ручной проверки человеком не было.
