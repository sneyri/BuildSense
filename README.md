# BuildSense — учебный визуальный редактор дома


BuildSense позволяет человеку без опыта проектирования собрать трёхмерную модель дома из строительных
элементов, менять их, видеть геометрические ошибки и потенциальные конструктивные проблемы, запускать
наглядную демонстрационную симуляцию разрушения и выгружать модель во FreeCAD.

Это **учебный прототип**: не замена CAD/BIM-системам и не инженерный расчёт. Проверки конструкции —
эвристики («потенциальная проблема», «требуется инженерная проверка»), симуляция — демонстрация заданного
сценария, нормы — только сверенные пункты документов, остальное явно помечено.

**Открыть онлайн:** https://sneyri.github.io/freecad-snip-checker/ · пример с ошибками: https://sneyri.github.io/freecad-snip-checker/#example=issues&wizard=0

Пошаговое руководство для пользователя — [TUTORIAL.md](TUTORIAL.md).

## Запуск

**Ничего устанавливать не нужно**: ни сервера, ни Python, ни интернета.

- Windows: двойной щелчок по `index.html` (или `start.bat`).
- Linux / RedOS: откройте `index.html` в Firefox, Chromium или Яндекс.Браузере (или `sh start.sh`).

Нужен браузер с WebGL. Библиотека Three.js r147 лежит локально в `vendor/three/` (лицензия MIT).
Запуск по `file://` проверен в Microsoft Edge (Chromium) на Windows 11 — см. [docs/TESTS.md](docs/TESTS.md).

Последний проект автоматически сохраняется в браузере (localStorage). Файлы проекта — `*.buildsense.json`.

## Сценарий демонстрации (7–10 минут)

1. Откройте `index.html` — загрузится стартовый дом, справа появится **мастер** из 8 шагов.
2. «Новый» → «Пустой проект». Мастер: шаг 1 — «Создать плиту фундамента»; шаг 2 — «Стены по контуру фундамента»;
   шаг 3 — «Пол первого этажа», «Добавить этаж»; шаг 4 — «Расставить автоматически»; шаг 5 — «Крыша над домом».
3. Постройте что-нибудь мышью: палитра «Объекты» → «Стена» → два щелчка (магнит к углам и граням), «Колонна» → щелчок.
4. Выберите стену и поднимите её (Z+) — красная подсветка и ошибка «зазор до опоры»; во вкладке «Проблемы» щёлкните
   сообщение (камера покажет стену) и нажмите «Исправить».
5. «Новый» → «Пример: дом с ошибками» — разбор ошибок каждой категории, фильтры по уровню и категории.
6. Вкладка «Симуляция» → «Отказ опоры» → выберите стену → «Запустить»: шаги, подсветка, опрокидывание,
   «До / после», «Восстановить исходное».
7. Вкладка «Правила» → добавьте учебное правило (например, «Сечение колонны ≥ 0,4 м») — оно сразу проверяется.
8. «Сохранить», затем «Открыть» сохранённый файл; «Экспорт в FreeCAD» → макрос `freecad/import_house.FCMacro` во FreeCAD.

Примеры открываются и по ссылке: `index.html#example=twoStorey`, `#example=issues`, `#example=section` (жилая секция, 5 этажей), `#example=starter`
(дополнительно `&wizard=0`, `&view=top`, `&tab=problems`).

## Возможности

| Область | Что работает |
|---------|--------------|
| Объекты (35 типов) | фундаменты: плита, лента, столбчатая и круглая опоры, сваи; стены (наружные, внутренние, перегородки), колонны (прямоугольные, круглые), балки, перекрытия, перемычки, фермы, лестницы, площадки; крыши: плоская, односкатная, двускатная, вальмовая; окна и двери с проёмами; балкон, терраса, перила, дымоход, комнаты-зоны, карниз; трубы, унитаз, раковина, ванна, светильник, розетка, выключатель; кровать, стол, стул, диван, шкаф |
| Построение | палитра + мышь: по двум точкам (цепочкой), прямоугольником, щелчком в точку (R — поворот), щелчком по стене; привязки к углам, граням, осям, сетке (5 см – 1 м); элементы садятся на фундамент/перекрытие; стены стыкуются встык |
| Редактирование | выбор щелчком и в дереве (Ctrl — несколько), перетаскивание, X/Y/Z с шагом сетки, поворот, размеры в свойствах, дублирование (Ctrl+D), копирование на этаж, удаление (Del), отмена/повтор (Ctrl+Z / Ctrl+Y, 100 шагов) |
| Этажи | несколько этажей; «+ Этаж» — перекрытие по наружным стенам и копия стен с окнами |
| Вид | перспектива / ортография, план сверху, фасад, изометрия, «вписать», изоляция (I), скрытие категорий, габариты, тёмная и светлая тема |
| Проверки | геометрия, конструкция, нормы — автоматически после каждого изменения; цвета, фильтры, переход к элементу, кнопки «Исправить» ([docs/CHECKS.md](docs/CHECKS.md)) |
| Правила | реестр в `data/rules/`; пользовательские учебные правила через форму или импорт JSON, экспорт своих правил |
| Симуляция | 5 детерминированных сценариев, пошаговый показ, «до/после», восстановление ([docs/SIMULATION.md](docs/SIMULATION.md)) |
| Расчёты | объём, масса, собственный вес, нагрузка, проверка балки по формулам сопромата с формулами и допущениями |
| Мастер | 8 шагов: фундамент → стены → этажи → окна и двери → крыша → проверка → симуляция → экспорт |
| Файлы | проект JSON (схема 2, миграция прежнего формата), экспорт JSON для FreeCAD в мм ([docs/JSON_FORMAT.md](docs/JSON_FORMAT.md)) |
| FreeCAD | макрос: BIM-объекты Arch (Wall, Window, Structure, Stairs, Space, этажи) и примитивы Part; отчёт о неподдерживаемом; сохранение `.FCStd` и **IFC4** (в режиме BIM) |
| BIM-код | код каждого элемента по правилу именования `объект-секция-Э<этаж>-<раздел>-<тип>-<номер>` (например `ЖК01-С1-Э02-КР-ПЛТ-003`): в свойствах, в экспорте, во FreeCAD (`BuildSenseBimCode`, описание объекта) |
| Модульные узлы | палитра «Модульные узлы (ГОСТ)»: наружная стеновая панель (ГОСТ 11024-2024), стена из газобетона (ГОСТ 31360-2024), плита многопустотная (ГОСТ 9561-2016), лестничный марш (ГОСТ 9818-2015); размеры узлов — демонстрационные, соответствие типоразмерам стандарта **не сверено** (показывается пользователю) |
| Оболочка здания | площади наружных стен, окон, дверей, покрытия, доля остекления фасадов, объём и компактность A/V по габаритам — исходные данные для теплотехнического расчёта по СП 50.13330 (сам расчёт не выполняется) |

## FreeCAD

1. В BuildSense: «Экспорт в FreeCAD» → `<имя>.freecad.json`; рядом кнопка «Скачать макрос» → `import_house.FCMacro`
   (тот же файл, что `freecad/import_house.FCMacro`; встроен в `js/io/macroSource.js`, после правки макроса — `node tools/build-macro.js`).
2. Во FreeCAD: **Макрос → Макросы…** → папка со скачанным макросом → `import_house` → **Выполнить** → выбрать файл → сохранить `.FCStd`.

Режим BIM (по умолчанию): стены — Arch Wall, окна и двери — Arch Window с вырезом в стене, фундаменты, плиты,
колонны, балки, перемычки — Arch Structure с IFC-типом, лестницы — Arch Stairs, комнаты — Arch Space, этажи — BuildingPart.
Крыши, фермы, перила, трубы, сантехника, мебель — параметрические примитивы Part (не BIM-объекты).
Если BIM-объект создать не удалось, элемент строится примитивом Part, причина — в отчёте импорта.
Переменная `BUILDSENSE_MODE=part` — только примитивы Part.
В режиме BIM рядом с `.FCStd` сохраняется `.ifc` (IFC4, средствами FreeCAD и ifcopenshell); `BUILDSENSE_IFC=<путь>` — свой путь, `BUILDSENSE_IFC=0` — не сохранять.
Каждому объекту записываются `BuildSenseId`, `BuildSenseBimCode` и, для узлов библиотеки, `BuildSenseNode` (название и стандарт).

**Проверено на FreeCAD 1.1.4 (Windows x64)** — консольный и графический режимы, BIM и Part, габариты всех
объектов сверены с JSON (см. [docs/TESTS.md](docs/TESTS.md)). Другие версии FreeCAD не проверялись.

## Структура

```
index.html, css/app.css         интерфейс (тёмная тема по умолчанию)
vendor/three/                   Three.js r147 + OrbitControls (локально)
js/core/                        пространство имён BuildSense, геометрия плана
js/materials/                   материалы (плотность, модуль упругости, учебное [σ])
js/objects/                     реестр типов, формы, опирание, привязки, модель проекта и команды
js/editor/                      инструменты мыши, история отмены
js/scene/                       3D-сцена, построение геометрии, габариты
js/validation/                  параметры модели, движок проверок
js/rules/                       реестр правил, проверка норм, встроенные правила
js/simulation/                  граф опирания, сценарии, показ в 3D
js/calculations/                упрощённые расчёты
js/io/                          проект JSON, экспорт для FreeCAD
js/ui/                          панели: палитра, дерево, свойства, проблемы, симуляция, правила, проект, мастер
js/app.js                       контроллер: edit() → снимок для отмены → изменение → проверки → перерисовка
data/rules/                     правила (источник истины), docs/ — документация
examples/                       демонстрационные проекты и экспорт; examples.js — для меню «Новый»
freecad/import_house.FCMacro    макрос импорта
tests/                          автотесты Node.js и Python, тест в настоящем FreeCAD
tools/                          генераторы встроенных правил и примеров
```

Все модули — обычные скрипты в общем пространстве имён `BuildSense` (так работает `file://`). Модули без DOM
(`core`, `materials`, `objects`, `rules`, `validation`, `simulation`, `calculations`, `io`, `editor/history`)
загружаются в Node.js для тестов (`tests/loader.js`).

**Интерфейсы ключевых модулей:**

| Модуль | Функции |

| `BuildSense.validation` | `validate(project) → { issues, summary, norms, ruleErrors }`, `severityByElement`, `applyFix` |
| `BuildSense.ruleRegistry` | `builtin`, `all(project)`, `makeUserRule`, `importRules` |

| `BuildSense.simulation` | `run(project, scenario, options) → { steps, failed, damaged, report, assumptions }` |

## Ограничения и развитие

**Ограничения.** Стены только прямые; проёмы прямоугольные; крыша — один объём над прямоугольником; помещения —
условные зоны (не вычисляются из стен); нет манипуляторов трансформации в 3D (перемещение мышью по плану и числами);
расчёты и симуляция — учебные; проверено в Edge/Chromium на Windows и в FreeCAD 1.1.4.

**План развития.**
1. Манипуляторы перемещения и поворота в 3D, выделение рамкой.
2. Стены по полилинии с автоматическими углами, наклонные и криволинейные стены.
3. Помещения, вычисляемые из контура стен; площади и нормы по комнатам.
4. Крыши по произвольному контуру (Arch Roof), мансарды.
5. Нагрузки по этажам и расчётная схема (сбор нагрузок по грузовым площадям), проверка по сверенным нормам.
6. Проверка открытия IFC в отечественных BIM-системах (Renga, nanoCAD BIM), загрузка в Pilot-BIM; импорт обратно в BuildSense.
7. Расширение реестра сверенных правил: СП 54.13330.2022 для многоквартирных домов, СП 1.13130, СП 59.13330 и др. — только после сверки по тексту.
8. Проверка в Firefox и на RedOS, сенсорное управление.
9. Сверка типоразмеров узлов с текстами стандартов; узлы «санитарно-техническая кабина» (ГОСТ 18048-2018) и «шахта лифта» (ГОСТ 17538-2016).
10. Теплотехнический расчёт оболочки по СП 50.13330 на основе посчитанных площадей.
