# Машиностроение: параметрические детали

Режим «Машиностроение» — учебный конструктор типовых деталей тел вращения: **втулка**, **ступенчатый вал**,
**фланец** с отверстиями по окружности. Пользователь вводит размеры в мм, модель сразу перестраивается;
проект сохраняется в JSON, экспортируется в STL (сетка) и в JSON для FreeCAD, где макрос строит точные
твёрдые тела и STEP.

**Источник истины — параметры детали.** Сетка в браузере и в Blender — многогранное приближение для показа
и STL. Точные тела строит ядро OpenCASCADE в FreeCAD (`freecad/import_parts.FCMacro`).

## Какие операции нужны (краткое исследование)

Веб-документация FreeCAD (wiki) и справка AutoCAD Mechanical при попытке чтения были недоступны
(страница защиты от ботов / пустая справка), поэтому список сверялся по самому FreeCAD 1.1.4:
`Document.supportedTypes()` содержит `PartDesign::Pad, Pocket, Revolution, Groove, Hole, Chamfer, Fillet,
PolarPattern, LinearPattern, Mirrored` и др. Для деталей курса ТМ этого набора достаточно:
- втулка и вал — **Revolution** замкнутого эскиза в плоскости, проходящей через ось (ступени — вершины эскиза);
- фаски на торцах — **Chamfer** (здесь фаска 45° вносится в эскиз профиля — для тела вращения это то же тело);
- центральное отверстие — внутренний контур эскиза вращения (или **Pocket/Hole**);
- отверстия фланца — **Hole/Pocket** + **PolarPattern** (n штук на окружности ⌀Dотв);
- шпоночный паз вала — будущая операция **Pocket** (вырез по эскизу паза на касательной плоскости ступени);
- галтели на уступах — будущая операция **Fillet** (скругление ребра профиля).

## Формат проекта

```json
{ "format": "buildsense-mech", "schemaVersion": 2, "units": "mm", "name": "…", "assemblies": [ … ],
  "parts": [ { "id": "p1", "type": "bushing", "name": "Втулка",
               "params": { "D": 40, "d": 25, "L": 30, "c": 1, "ci": 0.5 },
               "placement": { "x": 0, "y": 0, "z": 0, "rotation": { "x": 0, "y": 0, "z": 0 } },
               "material": "steel" } ] }
```

Параметры (мм): втулка `D, d, L, c` (наружная фаска ×45°), `ci` (внутренняя); вал `steps:[{d, L}…], c1, c2`
(фаски торцов); фланец `D, T` (толщина диска), `d` (центральное отверстие), `hubD, hubH` (ступица, 0 — нет),
`n, pcd, holeD` (n отверстий ⌀holeD на окружности ⌀pcd). Локальная ось детали — Z, левый торец на z = 0;
поворот — углы Эйлера в градусах, матрица Rx·Ry·Rz (как `THREE.Euler "XYZ"`; так же в макросе и в Blender).
Материалы — справочные приближённые плотности (сталь 7850, чугун 7200, алюминиевый сплав 2700, бронза 8800,
латунь 8500, полиамид 1150 кг/м³) — только для учебной оценки массы.

## Сборки (схема 2)

```json
"assemblies": [ { "id": "A1", "name": "Узел вала",
  "components": [ { "id": "c1", "partId": "p1", "fixed": true }, { "id": "c2", "partId": "p2", "fixed": false } ],
  "mates": [ { "id": "m1", "type": "coaxial", "orient": "auto", "a": { "comp": "c1", "ref": "axis" }, "b": { "comp": "c2", "ref": "axis" }, "suppressed": false },
             { "id": "m2", "type": "planar", "mode": "contact", "offset": 0, "a": { "comp": "c1", "ref": "step2" }, "b": { "comp": "c2", "ref": "end0" }, "suppressed": false } ] } ]
```

- **Компонент** — ссылка на деталь проекта (`partId`). Деталь остаётся отдельной: свои размеры, материал,
  дерево фич; сборка меняет только её `placement`. Деталь входит не больше чем в одну сборку.
- **Сопряжения:** `coaxial` — совместить оси (`orient`: `auto` — по граням или как сейчас, `same`, `opposite`);
  `planar` — плоские грани `contact` (встык, нормали навстречу) или `align` (заподлицо); `distance` — осевое
  смещение `offset` мм между гранями вдоль нормали грани стороны `a`. Закрепление — `fixed` у компонента;
  сопряжение можно временно подавить (`suppressed`).
- **Привязки** выводятся из профиля: `axis`; торцы `end0`, `end1`; уступы вала `step1…` (между ступенями i и i+1,
  только если диаметры разные); у фланца со ступицей ещё `disk` (верх диска). Если грань исчезла после изменения
  размеров, сопряжение получает статус «ошибка: нет плоской грани», а не изображается решённым.
- **Решатель** — конструктивный, от закреплённых компонентов: направление оси (соосность и/или грани), затем
  перенос вдоль свободного направления. Остальные сопряжения проверяются по невязке (≤ 1e‑4 мм, ось — |sin| ≤ 1e‑7).
  Статусы компонента: закреплён / определён / недоопределён (с перечнем свободных перемещений; положение по ним
  остаётся текущим) / не связан с закреплёнными / конфликт. Поворот тела вращения вокруг собственной оси
  сопряжениями не ограничивается — это сказано в статусе.
- **Отказы при создании:** сам с собой, ось вместо грани и наоборот, несуществующая грань, нечисловое или
  отрицательное (для «встык») смещение, повтор, а также любое сопряжение, которое при пробном решении оказалось
  в конфликте с уже заданными. Сборка при отказе не меняется, текст причины показывается в форме и в строке состояния.
- **Контакт и пересечения.** Для «граней встык» проверяется, перекрываются ли кольца граней (иначе статус «нет
  контакта»). Для каждой пары соосных деталей с пересекающимися габаритами считается объём общей части по профилям
  (без отверстий фланца); объём > 0,001 мм³ — ошибка «пересекаются, это не соединение». Для несоосных пар — только
  сообщение, что точная проверка не выполнялась. Касание и отсутствие пересечений — геометрия, а не доказательство
  работоспособности: посадки, прочность и возможность сборки не проверяются.
- **Интерфейс:** кнопки «Сборка» и «Учебная сборка»; в дереве — сборка, компоненты и сопряжения со статусами;
  в свойствах детали — раздел «Сборка» (включить, закреплён, сопряжения, форма нового сопряжения, исключить);
  в свойствах сопряжения — режим, направление, смещение, «подавить», удалить. Поля положения и перетаскивание
  мышью для определённого сопряжениями компонента заблокированы с объяснением.
- **Экспорт FreeCAD:** без сборок — схема 1, как раньше (читается и прежним макросом); со сборками — схема 2:
  `assemblies` с компонентами, сопряжениями, статусами и сообщениями. Макрос создаёт для сборки `App::Part`,
  кладёт в него отдельные `Part::Feature` компонентов (в решённых положениях) и пишет сопряжения в свойство
  `BuildSenseMates`. Это запись структуры, а не связи верстака Assembly: FreeCAD сопряжения не пересчитывает.
- **Учебная сборка** (`createDemoAssemblyProject`): вал ⌀30/⌀50 (буртик)/⌀40/⌀25 закреплён; фланец соосно и
  встык нижним торцом к буртику (кольцо касания r 20…25 мм); втулка соосно с зазором 5 мм от уступа ⌀40→⌀25.
  Удлините буртик или поменяйте смещение — фланец и втулка переедут; размеры фланца и втулки меняются независимо.

## Дерево фич

`mechModel.features(part)` выдаёт список: `sketch` (замкнутый профиль в плоскости RZ) → `chamfer`
(фаски 45° на вершинах эскиза) → `revolve` (360° вокруг Z) → `hole` (сквозные отверстия, массив `polar`).
`evaluate(part)` вычисляет итоговый профиль и координаты отверстий; их используют и сетка, и макрос, и Blender.
Новая операция (выдавливание, вырез, скругление, шпоночный паз) добавляется как новый `kind` в `features`,
в `evaluate`/`mechGeometry` и в `build_shape` макроса. Сборки — следующий уровень над `parts`.

## Проверки параметров

Ошибки — на русском, с полем (`{ field, message }`), поле подсвечивается в панели, модель не меняется.
Все числа конечные и не меньше минимума; `d < D`; стенка втулки `(D − d)/2 ≥ 1 мм`; фаски помещаются в стенку
и длину; у вала хотя бы одна ступень, фаска торца меньше `d/2 − 1` и длины ступени; у фланца ступица меньше D
и толще 1 мм, отверстия не выходят за край (`pcd/2 + holeD/2 ≤ D/2 − 1`), не задевают ступицу/центральное
отверстие и не пересекаются (`pcd·sin(π/n) − holeD ≥ 1`). Значения 1 мм — **учебные ограничения программы**,
а не нормативные требования; конструктивные минимумы стенок и перемычек берутся из справочников и ГОСТ.

## Геометрия и объём

- Тело вращения: каждое ребро профиля — своя `THREE.LatheGeometry` (128 сегментов), рёбра остаются острыми.
  Полая втулка — профиль-прямоугольник r…R, а не «труба поверх цилиндра».
- Фланец: грани диска — `THREE.Shape` с `holes` (триангуляция `THREE.ShapeUtils`), стенки отверстий и ступицы
  сшиты в **одну** замкнутую оболочку. `ExtrudeGeometry` диска + отдельная ступица дали бы две касающиеся
  оболочки с внутренними гранями — для STL и проверки на замкнутость это хуже.
- Объём: формулы из параметров (цилиндры минус кольца фасок по Паппу–Гульдину, минус отверстия) = объём по
  профилю (формула Гаусса + Папп) с точностью 1e‑12; сетка вписана в окружности и даёт на 0,03–0,04 % меньше.
- STL — двоичный, в мм, все детали в мировых координатах.

## Ограничения

- Только тела вращения с осью Z и сквозные отверстия, параллельные оси; шпоночный паз, галтели, резьба,
  выдавливание произвольного эскиза пока не реализованы (архитектура фич это допускает).
- Сборки: привязки — только ось детали и плоские грани, перпендикулярные ей (нет осей отверстий фланца,
  цилиндрических граней, угловых сопряжений). Решатель не общий: несколько плоских сопряжений без соосности с
  непараллельными нормалями не решаются совместно (будет конфликт или недоопределённость, но не ложный успех).
  Поворот вокруг собственной оси не задаётся — для фланца угол отверстий остаётся как был. Вложенных подсборок нет.
- Пересечения точно считаются только для соосных деталей (без учёта отверстий фланца); для несоосных — нет.
- В FreeCAD сборка — контейнер `App::Part` с готовыми положениями; сопряжения не превращаются в связи Assembly.
- Фаски только 45° и только на торцах (у втулки — наружная и внутренняя).
- Макрос создаёт `Part::Feature` с готовой формой (не параметрическое дерево PartDesign): параметры
  сохраняются в свойствах `BuildSenseParams`, повторная правка — в BuildSense и новый импорт.
- Пересечения деталей вне сборок не проверяются.
