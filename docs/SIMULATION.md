# Демонстрационная симуляция и упрощённые расчёты

> **Демонстрационная симуляция иллюстрирует заданный сценарий и не является инженерным расчётом
> прочности, устойчивости или безопасности здания.** Это предупреждение показывается в панели и над сценой
> всё время, пока симуляция активна.

Модули: `js/simulation/loadGraph.js` (граф опирания), `js/simulation/simulation.js` (сценарии, без DOM),
`js/simulation/simPlayer.js` (показ в 3D). Проект симуляцией **не изменяется**: «Восстановить исходное»
возвращает 3D-объекты на место, а любая правка модели сбрасывает симуляцию.

## Модель

1. **Граф опирания.** Для каждого элемента вычисляется, на чём он стоит: элемент B — опора A, если верх B совпадает с низом A
   (допуск 2 см) и контур A лежит на B. Вес опоры — доля контрольных точек A, лежащих на B (для плоских элементов — поровну
   между опорами). Проёмы и перемычки «держатся» своей стеной, навесные элементы — примыкающей стеной/перекрытием, фундаменты — грунтом.
2. **Начальный отказ** задаётся сценарием.
3. **Распространение волнами.** Элемент отказывает, если у него не осталось опор или доля оставшегося опирания меньше порога
   (по умолчанию 50 %, настраивается). При частичной потере опор элемент отмечается как повреждённый и остаётся на месте.
4. **Движение на экране.** Высокие элементы (стены, колонны, дымоход) опрокидываются на 75° вокруг нижнего ребра в сторону от уцелевших опор
   (стена без опор — наружу); плоские проседают с поворотом вокруг уцелевшей опоры до нижележащего основания. Это наглядная иллюстрация, а не деформации.

Случайные числа не используются: одинаковые данные дают одинаковый результат (это проверяет автотест).

## Сценарии

| Сценарий | Что задаётся | Правило |
|----------|--------------|---------|
| Отказ опоры | выбранный несущий элемент | элемент перестаёт работать |
| Перегрузка перекрытия | перекрытие, нагрузка q (кПа), условная несущая способность (кПа) | g = ρ·9,81·t/1000; отказ при q + g > [q] |
| Потеря устойчивости стены | стена (или самая гибкая по h/t) | стена опрокидывается |
| Каскадный отказ | элемент и порог опирания | как «отказ опоры» с вашим порогом |
| Боковое воздействие | интенсивность k (0–3), направление | индекс R = (t/h)·(1 + n), n — число примыкающих стен; опрокидываются элементы с R < 0,1·k |

Шаги показа: исходное состояние → воздействие (фиолетовая подсветка) → начальный отказ → волны отказов → итог.
Цвета: красный — отказ, оранжевый — частичная потеря опоры. «До / после» — полупрозрачный «призрак» исходной модели.

## Ограничения

- Нет расчёта усилий, деформаций, динамики, материалов и соединений; несущая способность — пользовательское число.
- Опирание определяется только геометрическим контактом; анкеровка, жёсткие узлы, связи не моделируются.
- Боковое воздействие — безразмерная условная величина, а не ветровая или сейсмическая нагрузка по нормам.
- Результат нельзя использовать для выводов о безопасности реального здания.

## Упрощённые расчёты (`js/calculations/calculations.js`)

Вкладка «Свойства» → «Расчёт (упрощённый)» для выбранного элемента: формула, исходные данные, единицы, допущения.

| Величина | Формула |
|----------|---------|
| Объём | по форме (стена — за вычетом проёмов; крыша, ферма, лестница, мебель — оценка, отмечена) |
| Масса | m = ρ·V (типичные плотности материалов, `js/materials/materials.js`) |
| Собственный вес | G = m·g / 1000, кН |
| Нагрузка на плиту | Q = q·A; N = G + Q |
| Балка / перемычка | однопролётная шарнирно опёртая, равномерная нагрузка: q = ρ·g·b·h/1000 + qзад; M = qL²/8; V = qL/2; W = bh²/6; σ = M/W; I = bh³/12; f = 5qL⁴/(384EI); проверки σ ≤ [σ], f ≤ L/n |

[σ] — **учебное допустимое напряжение**, задаётся пользователем; E — типичный модуль упругости материала.
Не учитываются устойчивость, опорные зоны, коэффициенты надёжности и требования норм. Это не расчёт здания.
