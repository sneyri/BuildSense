# Автоматические проверки BuildSense

Модуль: `js/validation/validationEngine.js`. Проверки запускаются после **каждого** изменения модели.
Каждое сообщение содержит: идентификатор проверки, категорию, уровень, описание, ссылки на элементы и
пояснение «что проверить»; у некоторых есть кнопка «Исправить».

| Уровень | Цвет | Значение |
|---------|------|----------|
| `error` | красный | ошибка |
| `warning` | оранжевый | предупреждение |
| `info` | синий | информация |
| `pass` | зелёный | проверка пройдена |

**Геометрическая ошибка** доказывается геометрией модели (зазор, пересечение, проём за стеной).
**Конструктивная проблема** — эвристика: формулируется как «потенциальная проблема» или «требуется инженерная проверка»,
а не как доказанное разрушение. **Нормы** — правила из реестра со статусом достоверности.

## Геометрия

| ID | Что проверяется | Уровень |
|----|-----------------|---------|
| `GEO-SIZE` | нулевые, отрицательные, нечисловые размеры | ошибка |
| `GEO-COORD` | нечисловые координаты или дальше 1 км от начала | ошибка |
| `GEO-SITE` | элемент за границей участка или выше предельной высоты | предупреждение |
| `GEO-OVERLAP` | пересечение объёмов (кроме стена–стена — см. `GEO-WALLS`). **Допустимы**: фундаменты между собой, перемычка/колонна в стене, плита в стене, концы балок и ферм в опорах, лестница сквозь перекрытие, дымоход сквозь крышу, балкон и карниз у стены. Проёмы и зоны комнат не учитываются | предупреждение |
| `GEO-OPENINGS` | проём без стены, за границами стены, наложение проёмов | ошибка |
| `GEO-CONNECT` | зазор между низом элемента и опорой (кнопка «Опустить на опору»); торец наружной стены ни к чему не примыкает; зазор между верхом стены и перекрытием | ошибка / предупреждение |
| `GEO-WALLS` | стыки стен: щель в углу (> 0,002 м² на плане), торец выступает за грань соседней стены, две стены друг в друге или пересекают одна другую. **Допустимы**: угловой стык (Г) — в т. ч. с нахлёстом в непрямом углу, Т-стык (торец упирается в стену не глубже её толщины) | предупреждение / ошибка |
| `GEO-LEVELS` | совпадение отметок: низ стены ниже верха фундамента/плиты (кнопка «Поставить на верх опоры»); стена выходит за край опоры (> 2 % площади); перекрытие над этажом ниже верха стен; верх перекрытия не совпадает с отметкой своего этажа | предупреждение |
| `GEO-STAIRS` | верх лестницы не совпадает с отметкой следующего этажа (> 5 см) | предупреждение |
| `GEO-ROOF` | крыша не покрывает наружные стены верхнего этажа; нет крыши | предупреждение / инфо |

## Конструкция (предварительно, эвристики)

| ID | Что проверяется | Уровень |
|----|-----------------|---------|
| `STR-FOUNDATION` | в проекте есть стены, но нет фундамента (кнопка «Добавить плиту под стенами») | ошибка |
| `STR-SUPPORT` | под элементом нет опоры; опирание частичное (консольный свес) | ошибка / предупреждение |
| `STR-BEAMS` | конец балки или фермы без опоры; пролёт больше учебного предела; пролёт / высота сечения больше предела | ошибка / предупреждение |
| `STR-PROFILE` | размеры меньше учебного профиля (толщины стен, сечение колонны, толщина перекрытия) | предупреждение |
| `STR-SLABS` | междуэтажное перекрытие опирается меньше чем на два несущих элемента; пролёт больше учебного предела | ошибка / предупреждение |
| `STR-SLENDER` | гибкость стены h/t больше предела; отдельно стоящая стена (кнопка «Увеличить толщину») | предупреждение |
| `STR-LOADPATH` | несущий элемент опирается на ненесущий — нагрузка не доходит до фундамента | предупреждение |
| `STR-LEVELS` | у этажа нет перекрытия на его отметке — нет связи между этажами | предупреждение |
| `STR-ROOF` | крыша не опирается на стены (кнопка «Положить крышу на стены») | ошибка |
| `STR-ATTACHED` | балкон, карниз, светильник, розетка не примыкают к стене или перекрытию | ошибка / предупреждение |
| `STR-OPENINGS` | узкий простенок (< 0,25 м), проёмы занимают > 60 % длины несущей стены, нет перемычки над проёмом ≥ 1 м (кнопка «Перемычки») | предупреждение / инфо |

Пороговые значения — пользовательский «учебный профиль» (вкладка «Проект»), а не нормативы.

## Нормы и правила

| Правило | Требование | Статус |
|---------|------------|--------|
| СП 55.13330.2016, п. 1.1 | **область применения документа**: не более 3 надземных этажей; высота не более 20 м. При невыполнении — «СП 55 не применяется» (информация), остальные пункты СП 55 не проверяются | сверено (ред. Изм. № 2, 2023) |
| СП 55.13330.2016, п. 6.2 | высота комнат и кухни ≥ 2,7 м (IА, IБ, IГ, IД) / ≥ 2,5 м (остальные районы) — **по каждому этажу**; этаж без перекрытия под скатной крышей при недостаточной высоте у стен — «требуется проверка» | сверено (ред. Изм. № 2) |
| СП 55.13330.2016, п. 6.1 | общая комната ≥ 16 м², спальня ≥ 8 м², кухня ≥ 8 м² — для гос. и муниципального фонда | сверено (ред. Изм. № 2) |
| СП 55.13330.2016, п. 9.18 | световые проёмы : площадь пола ≥ 1 : 8 | требует проверки (сверено только с ред. 2018 г.) |
| DEMO D.1–D.4 | толщина стены, ширина и высота двери, уклон крыши | демонстрационные, не нормы |
| `USER-*` | правила пользователя | учебные ограничения |

PASS/FAIL выдаются только для сверенных правил и (с пометкой) для учебных ограничений.
FAIL сверенного правила — ошибка; FAIL учебного ограничения — предупреждение; NOT VERIFIED — информация.

Статусы результата правила:

| Статус | Когда | Уровень |
|---|---|---|
| `PASS` | правило применимо, данных достаточно, требование выполнено | пройдено |
| `FAIL` | требование не выполнено | ошибка (сверено) / предупреждение (учебное) |
| `NOT VERIFIED` | правило не сверено, демонстрационное или в модели нет данных | информация |
| `NEEDS REVIEW` | по модели требование не выполнено, но выполнено условие `undecidable` правила (например, наклонный потолок) — вывод о нарушении не делается | предупреждение (сверено) |
| `OUT OF SCOPE` | не выполнено правило области применения (`role: "scope"`) — документ к объекту не применяется | информация |

Правила документа вне его области применения и встроенные проверки, которым в модели нечего проверять (например, «Балки» без балок),
попадают в список **«Не применялись»** внизу вкладки «Проблемы», а не в «пройдено».

Поля правила: `role: "scope"` — правило области применения документа; `undecidable: [{ parameter, operator, value, reason }]` — условия,
при которых FAIL заменяется на NEEDS REVIEW с причиной; `applicability.elementType: "storey"` — проверка по каждому этажу
(параметры этажа: `room.clearHeight`, `storey.slopedCeiling`).

## Подсветка и переход к элементу

Элементы с ошибкой подсвечиваются в 3D красным, с предупреждением — оранжевым, в дереве — цветной точкой.
Щелчок по сообщению выбирает элементы и наводит на них камеру. Фильтры: уровень (чипы) и категория.
